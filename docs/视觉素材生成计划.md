# 六爻占卜 — 视觉素材生成计划

> 日期：2026-07-14  
> 工具：Dreamina CLI（seedance 5.0 pro）+ image2  
> CLI 路径：~/bin/dreamina.exe

---

## 分阶段计划

### Phase 1：核心交互素材（3 张）

优先级最高。用户直接触摸的东西，质感提升最明显。

| 素材 | 描述 | 尺寸 | 用途 |
|------|------|------|------|
| 龟壳 | 古铜色龟甲，正面俯视，纹理清晰，光从上方打下来 | 200×200 | 摇卦按钮，替换 CSS 椭圆 |
| 铜钱（正面） | 圆形方孔铜钱，古铜质感，表面有"道光通宝"类字样 | 100×100 | 铜钱落下的粒子 |
| 铜钱（反面） | 同上，反面图案 | 100×100 | 正反两种随机出现 |

流程：Dreamina 文生图 → image2 去背景透明 PNG → 集成到 TurtleShake.tsx

### Phase 2：Landing 主视觉（1~2 张）

| 素材 | 描述 | 尺寸 | 用途 |
|------|------|------|------|
| 首页 Hero | 古风占卜场景：案几上散落铜钱和龟壳，烛火摇曳，卦象暗纹。暖色调，安静庄重。 | 1200×800 | Landing Hero 背景 |

风格方向：不是卡通插画，古风摄影质感，类似《国家宝藏》文物特写的调性。

### Phase 3：稀有度特效素材（3~4 张）

| 素材 | 描述 | 用途 |
|------|------|------|
| 金光粒子纹理 | 细碎金色光点，金粉飘散 | 大吉特效叠加 |
| 暗色底纹 | 深灰墨色微光渐变 | 慎卦卡片边缘 |
| 金色描边纹理 | 细金线光晕 | 吉卦卡片装饰 |

### Phase 4：64 卦插画（分批）

第一批 4 张大吉卦象：
- 乾为天 — 苍穹云海、龙腾天际
- 坤为地 — 广袤大地、厚德载物
- 地天泰 — 天地交泰、万物通
- 水火既济 — 水火交融、事成圆满

风格：水墨意境，南宋山水小品，留白多，意境深。512×512。

## 一、支付接入

### 场景
- **订阅制**：月付/年付会员，解除每日 3 次限制
- **一次性购买**：龟壳皮肤、铜钱皮肤、背景皮肤
- **Donate/打赏**：免费用户自愿支持

### 候选方案

| 方案 | 适用场景 | 接入难度 | 备注 |
|------|----------|----------|------|
| **Stripe** | 国际用户，订阅+一次性 | 中等 | 国内需要营业执照+跨境收款资质 |
| **支付宝/微信支付** | 国内用户 | 需要企业资质 | 个人难接入，需注册个体户或公司 |
| **PayPal** | 国际 donate | 低 | 个人可接入，但国内提现麻烦 |
| **爱发电 / Patreon** | 创作者打赏 | 最低 | 直接外链，不做技术对接 |
| **Buy Me a Coffee** | 轻量 donate | 最低 | 外链，适合最低成本验证 |
| **Lemon Squeezy** | 全球数字商品 | 低 | 支持支付宝/微信/卡，个人可用 |

### MVP 建议
**先用外链 donate（爱发电/Buy Me a Coffee），不做技术对接。** 验证有付费意愿后再接 Stripe 或 Lemon Squeezy 做内建支付。

## 二、网络安全

### 已做的事
- [x] 密码 bcrypt 哈希（不存明文）
- [x] JWT 无状态认证（不含敏感信息）
- [x] Prompt 和 API Key 服务端隐藏
- [x] `.env` 不入 git
- [x] CORS 限制（当前 `*`，部署后收紧）
- [x] SQLAlchemy ORM（防 SQL 注入）

### 部署前必须做的事

| 项目 | 说明 | 优先级 |
|------|------|--------|
| **HTTPS** | 全站强制 HTTPS，Let's Encrypt 免费证书 | 🔴 必须 |
| **CORS 收紧** | `allow_origins` 改为实际域名，不能 `*` | 🔴 必须 |
| **JWT_SECRET 更换** | 生成随机 64 位密钥，替换 `dev-secret-...` | 🔴 必须 |
| **Rate Limiting** | API 限流（防刷占卜接口、防撞库） | 🟡 重要 |
| **CSRF 防护** | Next.js + JWT Bearer 天然免疫，但需确认 | 🟡 重要 |
| **输入消毒** | 用户问题输入做长度和内容过滤 | 🟡 重要 |
| **日志脱敏** | 不在日志中打印 email、password、token | 🟡 重要 |
| **备份策略** | 数据库定期备份（用户数据、占卜记录） | 🟢 上线后 |
| **DDoS 防护** | Cloudflare CDN 自带基础防护 | 🟢 上线后 |

### Cookie / Session 安全（如后续使用）
- JWT 目前存前端 localStorage（XSS 风险）
- 后续考虑 httpOnly cookie + refresh token 轮换

## 三、法律合规（中国大陆）

### 占卜类网站的特殊风险

> ⚠️ 严禁宣扬迷信。现行法规下，"占卜""算命"类内容属于敏感地带。

**合规底线：**
- 全站多处标注"仅供娱乐参考，请理性看待"
- 不给出医疗、投资等具体决策建议
- 不在判词中使用"一定""必然"等绝对化断言（已做到）
- 用户协议中明确：本服务为传统文化体验，不构成任何形式的预测或建议

**参考案例：**
- 主流八字/星座 App 均以"传统文化""性格分析"定位
- 避免使用"算命""改命""转运"等措辞
- 可用"易学文化体验""传统智慧分享"等表述

### 经营资质

| 需求 | 是否需要 | 说明 |
|------|----------|------|
| ICP 备案 | ✅ 必须 | 国内服务器必须备案 |
| 增值电信业务许可证（ICP 证） | ⚠️ 看情况 | 涉及收费经营可能需要 |
| 营业执照 | ✅ 需要 | 接入支付宝/微信支付的前提 |
| 网络文化经营许可证 | ⚠️ 看情况 | 文化类产品可能需要 |

## 四、MVP 到收钱的路径建议

```
现在 ────────────────→ 验证流量 ────────→ 开始收钱
│                        │                    │
│ 纯免费                │ 外链 donate        │ 内建支付
│ 验证产品留存          │ 爱发电/BMC         │ Stripe/Lemon Squeezy
│ 不做支付对接          │ 看有没有人给钱      │ 需要营业执照
│                        │                    │
│ 时间：上线后 1-3 个月   │ 时间：同期            │ 时间：验证后有付费意愿
```

**核心逻辑：先验证有人用、有人留、有需求，再为"收钱"做基础设施投入。** 如果免费都没人用，办营业执照和接支付就是浪费时间。

# 六爻占卜国际化网站 — 需求文档

> 版本：v1.0  
> 日期：2026-07-12  
> 状态：Phase 1 需求定义

---

## 一、项目目标

做一个面向全球的六爻占卜网站。用户登录后提出问题，通过摇龟壳动画完成起卦仪式，卦象逐爻动画生成。后台由专门的 subagent 生成模仿古诗对仗的中文判词。用户可点击展开对应语言的翻译和详细解读。提供卦象收集、稀有度系统和皮肤商城。氛围庄重有仪式感，同时有"仅供娱乐"的健康提示。

### 成功标准

1. 完整链路跑通：注册登录 → 提问 → 摇卦动画 → 卦象生成 → 判词输出 → 翻译解读
2. 六爻排盘算法正确（与主流六爻软件结果一致）
3. 判词质量达标（古诗风格、对仗工整、与卦象含义匹配）
4. 多语言翻译可用（首批：英文、日文）
5. 付费墙生效（免费用户每日限次，付费用户无限 + 皮肤）
6. 用户在 3 分钟内完成一次完整占卜

---

## 二、用户角色

| 角色 | 描述 |
|------|------|
| 访客 | 未登录，可浏览首页、了解六爻文化，看到起卦入口但点击后引导登录 |
| 免费用户 | 注册登录后，每日 3 次免费占卜 |
| 付费用户 | 订阅后无限次占卜，可购买皮肤，占卜历史永久保存 |
| 管理员 | 后台管理：查看用户数据、判词质量审核、皮肤上下架、公告发布 |

## 三、核心用户流程

```
首页（庄重仪式感）
  │
  ├── 浏览：六爻文化介绍、卦象展示墙
  │
  └── 开始占卜
        │
        ├── 未登录 → 登录/注册页（手机号或邮箱）
        │
        └── 已登录
              │
              ├── 检查今日剩余次数
              │   ├── 次数用完 → 提示升级付费 / 明天再来
              │   └── 次数可用 → 进入占卜流程
              │
              └── 占卜流程
                    │
                    ① 输入问题（或选择问题模板）
                    │
                    ② 摇龟壳交互（摇晃手机 / 点击按钮模拟摇签）
                    │    ├── 动画：龟壳晃动 → 铜钱飞出
                    │    └── 背景音效（可选，默认静音）
                    │
                    ③ 卦象逐爻生成动画
                    │    ├── 从初爻到上爻，每爻 1~2 秒渐变出现
                    │    ├── 阴阳爻有不同的视觉呈现
                    │    └── 六爻完成后 → 本卦完整展示
                    │
                    ④ 变爻触发（如有）
                    │    ├── 变爻高亮闪烁
                    │    └── 之卦（变卦）渐显
                    │
                    ⑤ 判词生成（后端 LLM，prompt 服务端隐藏）
                    │    ├── 显示"正在推演天机..."加载状态
                    │    ├── 中文古诗体判词逐字浮现
                    │    └── 稀有卦象触发金光 / SSR 特效
                    │
                    ⑥ 解读与翻译
                    │    ├── 默认显示中文判词
                    │    ├── 按钮：[查看详细解读] [切换语言]
                    │    ├── 点击详细解读 → 展开白话解析 + 爻辞原文
                    │    └── 切换语言 → 对应翻译版本
                    │
                    ⑦ 后续操作
                         ├── [收藏此卦] → 加入个人卦象收集册
                         ├── [再次占卜] → 回到步骤①
                         ├── [分享] → 生成卦象卡片图片
                         └── [查看收集册] → 成就与收集页面
```

### P0 — MVP 核心功能（首批交付）

| ID | 功能 | 描述 |

| F01 | 用户注册登录 | 手机号 + 邮箱两种方式，JWT 认证 |
| F02 | 六爻排盘引擎 | 传统三钱法起卦算法，输出本卦、变爻、之卦、互卦 |
| F03 | 摇卦交互动画 | 龟壳晃动 + 铜钱飞出 + 六爻逐行动画 |
| F04 | 卦象展示 | 本卦与变卦的卦象图（阴阳爻可视化） |
| F05 | 判词生成 | 后端 LLM 调用（prompt 服务端隐藏），生成古诗体中文判词 |
| F06 | 判词翻译 | 英文翻译（后续扩展日文等） |
| F07 | 详细解读 | 白话解析 + 爻辞引用 |
| F08 | 免费次数限制 | 每日 3 次，计数器重置 |

## 五、非功能需求

### 氛围与设计

- **主色调**：暖白底 + 深棕/暗金文字，避免纯黑
- **仪式感**：摇卦过程有"郑重其事"的感觉，不能像抽卡游戏一样轻浮
- **文字风格**：判词使用古诗对仗体，UI 文案简洁克制，不用网络用语
- **健康提示**：页面 footer 常驻 "占卜结果仅供娱乐参考，请理性看待"；首次使用时弹窗提醒
- **稀有特效**：SSR 卦象出现时，适度华丽（金光粒子、琴瑟和鸣音效），但不至于像赌博机

### 性能

- 首页加载 < 3 秒（含卦象展示墙动画）
- 摇卦动画 60fps，移动端流畅
- 判词生成（含 subagent 调用）< 15 秒
- 支持同时 100 用户在线

### 安全

- 密码加密存储（bcrypt）
- API 限流（免费用户 3 次/天 + 防止刷接口）
- XSS / CSRF 防护
- SQL 注入防护（ORM）

### 平台

- 响应式设计：桌面端 + 移动端（手机为主）
- 浏览器支持：Chrome / Safari / Firefox 近两年版本
- 不考虑原生 App（PWA 可做后续）

---

## 六、明确不做什么（MVP 范围外）

- 不做八字/紫微斗数等其他占卜体系
- 不做实时在线客服
- 不做社区/论坛/留言
- 不做区块链/NFT
- 不做 AI 占卜师自由对话（P2 再考虑）
- 不做视频直播占卜
- 不做小程序版本（先做 Web）

## 七、关键风险

| 风险 | 影响 | 缓解 |
|------|------|------|
| 六爻算法不准确 | 判词与卦象不匹配，用户信任崩塌 | 用已知六爻软件交叉验证算法输出 |
| LLM 判词质量不稳定 | 古诗体写不出来或语义不通 | 预设各卦基础判词模板 + LLM 润色；prompt 迭代调优 |
| 政策合规 | 占卜类网站可能被认定为迷信 | 全站多处"仅供娱乐"提示，强调文化体验属性 |
| 付费转化率低 | 收入无法覆盖成本 | 先用免费验证用户量和留存，付费墙后置 |
